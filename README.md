# 👟 Caruaru Calçados - Landing Page

Uma landing page simples, moderna e responsiva para uma loja de calçados, construída com foco em **HTML Semântico** e **CSS moderno**.

## 🎯 Objetivo
Divulgação e apresentação dos produtos da loja e redirecionamento para nossos consultores.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica utilizando tags como `<header>`, `<main>`, `<section>`, `<article>`, `<figure>` e `<address>`, evitando o uso de `<div>` para manter o código limpo e acessível.
- **CSS3**: 
  - **Flexbox & Grid Layout**: Para o alinhamento responsivo dos produtos e estruturação fluida da página.
  - **Variáveis CSS (Custom Properties)**: Para facilitar a manutenção e a alteração rápida do tema da loja (cores primárias, fontes e fundos).
  - **Design Responsivo**: Adaptação perfeita para dispositivos móveis, tablets e desktops utilizando Media Queries.

## 📋 Estrutura do Projeto

- `index.html`: Arquivo principal contendo toda a marcação semântica.
- `style.css`: Arquivo de estilo externo com todas as regras visuais.
- Imagens de placeholder (ex: `tenis-esportivo.jpg`, `sapato-social.jpg`, `sandalia-conforto.jpg`) prontas para serem substituídas pelas fotos reais dos produtos.

## 🛠️ Como Executar

Este é um projeto estático (Front-end puro), então não requer instalação de pacotes ou servidores complexos. 

1. Faça o download ou clone os arquivos.
2. Certifique-se de que o arquivo `index.html` e `style.css` estão na mesma pasta.
3. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador favorito (Google Chrome, Firefox, Edge, etc).

## ✨ Funcionalidades

- Menu de navegação com links âncora (direciona o usuário perfeitamente para as seções da página).
- Vitrine de produtos em formato de Grid que se reajusta automaticamente dependendo do tamanho da tela.
- Design limpo com efeito de `hover` nos cards dos produtos para melhor experiência do usuário.
- Seções bem definidas: Destaques, Lançamentos, Sobre a Loja e Informações de Contato.
